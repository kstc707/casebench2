# Casebench 2

Learn how real open-source projects work, from your first fork to your first merged pull request.

Casebench 2 is for people who know some code (data analysts, data scientists, students) but have never
contributed to open source. You follow a path: learn how projects work, practise on real changes that were
already merged, then contribute for real, with an AI coach that holds you to each project's own standards.
The first track is **scikit-learn**.

Status: early. See `.claude/team/roadmap.md` and `.claude/team/vision-anchor.md`.
